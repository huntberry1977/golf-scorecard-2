# ⛳ 골프 스코어카드

PC에서 실행하고 스마트폰으로 접속하는 모바일 웹앱입니다.

## 설치 및 실행

```bash
# 1. 의존성 설치 (최초 1회)
npm install

# 2. 서버 실행
npm start
```

## 폰에서 접속하기

1. PC와 스마트폰이 **같은 와이파이**에 연결되어 있어야 합니다
2. PC의 IP 주소 확인:
   - Windows: 명령 프롬프트에서 `ipconfig` → IPv4 주소
   - Mac: 터미널에서 `ifconfig | grep inet`
3. 폰 브라우저에서 `http://[PC IP 주소]:3000` 접속
   - 예: `http://192.168.1.5:3000`

## 기능

- 9홀 / 18홀 선택
- 동반자 스코어 함께 입력
- 매홀 타수 / 페어웨이 안착(FW) / 레귤러온(GIR) / 퍼팅 입력
- 핸디캡 및 네트 스코어 계산
- 라운드 요약 (홀별 결과 테이블)
- 통계 대시보드 (스코어 추이, FW/GIR/퍼팅 분석, 결과 분포)
- 구장별 홀맵 이미지를 등록하면 이후 라운드 시작 전과 스코어 입력 중 다시 볼 수 있습니다.
- 데이터는 `data/rounds.json`에 저장

## 데이터 백업

`data/rounds.json` 파일을 복사해두면 서버에 저장된 라운드 기록이 보존됩니다. 홀맵 이미지는 브라우저의 IndexedDB에 기기별로 저장되며 현재 백업 파일에는 포함되지 않습니다. 구장 홈페이지에서 받은 이미지 파일은 라운드 설정에서 구장명을 입력한 뒤 등록하세요. 같은 브라우저에서 해당 구장을 다시 입력하면 홀맵을 불러옵니다.
